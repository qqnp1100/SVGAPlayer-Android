# SVGA 加载配置测试页

在示例应用首页增加独立入口，使用现有 Coil 3 View 加载 API。页面从上到下依次为可滚动配置表单、加载按钮与状态、播放展示区域。配置区独立滚动，播放器保持可见。

配置包括 HTTP(S) 地址、请求头（每行 `名称: 值`）、namespace、解码尺寸、缓存策略、强/弱内存缓存与内存/磁盘读写覆盖、仅缓存、刷新、失败使用过期缓存、断点续传、Bitmap 格式、不可见图片过滤、inBitmap，以及循环次数、自动播放、静态首帧、速度、起止帧、倒放、隐藏行为和缩放方式。

输入修改立即保存到该页面专用 SharedPreferences，包括尚未通过验证的草稿；下次进入恢复。点击加载先校验 HTTP(S) 地址、数字、请求头与互斥选项，失败时定位具体字段。合法加载捕获独立快照，取消上次会话并重新加载，不受同 View 重复绑定复用影响。编辑表单不改变当前播放。

加载期间显示下载进度，完成显示从点击到可播放的耗时、素材尺寸/帧数/FPS、资源估算大小与已应用参数摘要。保留上一条完成结果用于对照，明确资源大小不是进程峰值内存。提供暂停、继续、重播和恢复默认。离开页面释放会话，恢复配置后等待用户点击加载。

验证使用本地 MockWebServer 提供现有 SVGA 资产，覆盖真实请求头、重复加载、播放参数生效、错误反馈、无效配置阻断及页面重建/重开后的配置恢复；构建 debug APK。
